# HAUS SIGNS Quotation Generator

A modern web application for generating professional quotations for HAUS SIGNS.

## Features

- 📝 Customer information form
- 🛒 Dynamic product items table with auto-calculation
- 🖼️ Image upload (drag & drop support)
- 📄 PDF export with premium template design
- 🎨 Modern dark theme UI
- 📱 Responsive design

## Tech Stack

- Vanilla JavaScript
- Vite (build tool)
- html2pdf.js (PDF generation)
- CSS3 with modern features

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/quotation-webapp.git

# Navigate to project directory
cd quotation-webapp

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build for Production

```bash
npm run build
```

## Usage

1. Fill in customer information
2. Add product items with descriptions, quantities, and prices
3. Upload layout images (optional)
4. Click "Preview" to review the quotation
5. Click "Export PDF" to download
